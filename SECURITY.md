# Security

If you find a vulnerability in BusySign, please report it privately through GitHub - the Security tab of this
repository, then "Report a vulnerability". Please don't open a public issue for it, and there is no other contact for
security reports.

In scope are the app and how it's built and released - the source in this repository, `scripts/build-app.sh`, the
workflows under `.github/workflows` and the source tarball attached to each release.

Fixes ship in a new patch release. A published release is never changed, so only the latest one gets them.
